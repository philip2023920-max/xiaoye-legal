## 產品一句話

一款 TABS 風格的簡化即時戰略遊戲，玩家是總司令，AI 參謀長會在每場戰役後學習玩家的戰略風格，越打越像「你的參謀長」。

## 目標玩家

- 喜歡 Company of Heroes、Total War 這類指揮型遊戲，但沒時間練 APM（每分鐘操作數）的成年玩家
- 對 AI 好奇、願意自備 API 金鑰的早期採用者（MVP 階段）

## 功能清單（MVP = M0～M2）

| # | 功能 | 說明 | 優先 |
|---|---|---|---|
| F1 | 戰鬥沙盤 | 俯視 3D 低多邊形地圖、2 方陣營、3 種單位（步兵／機槍／裝甲），單場 5～10 分鐘 | P0 |
| F2 | 決策節拍 | 每 20 秒或關鍵事件時，參謀長提出 1～3 條建議（結構化：單位、動作、目標、理由） | P0 |
| F3 | 總司令裁決 | 玩家對每條建議：採納／否決／修改後採納。一鍵採納會自動下令 | P0 |
| F4 | 指令驗證器 | 建議進遊戲前檢查合法性；不合法的退回參謀長並記錄 | P0 |
| F5 | 戰後檢討（AAR） | 戰後產出一頁報告：這場採納率、關鍵轉折、參謀長學到什麼 | P0 |
| F6 | 作戰準則（Doctrine） | 可閱讀、可編輯的 Markdown，記錄玩家風格與已驗證戰術；每場戰後自動更新 | P0 |
| F7 | 戰例庫回歸 | 準則更新後，用歷史戰局快照重跑參謀長，退步就回滾並告知玩家 | P1 |
| F8 | 參謀長人格旋鈕 | 謹慎／積極、話多／話少（文字即可，不做美術） | P2 |
| F9 | 準則匯出／匯入 | 把「我的參謀長」帶到另一台電腦或分享給朋友 | P2 |

## 使用者流程（一場戰役）

1. 開局 → 參謀長讀作戰準則，用一句話說明「我記得您偏好……這場我會……」
2. 戰鬥中 → 每個決策節拍彈出建議卡片；玩家點採納／否決；遊戲照常進行不暫停
3. 關鍵事件（部隊潰散、佔領據點）→ 參謀長插話一次
4. 戰鬥結束 → AAR 報告 → 顯示準則「新增了 N 條、刪除了 M 條」，玩家可一鍵撤銷
5. 下一場 → 重複；玩家應該在第 3～5 場明顯感到「它懂我了」

## 成功定義

| 指標 | 目標 |
|---|---|
| 參謀長建議採納率 | 第 1 場 < 40%，第 5 場 > 70%（同一玩家） |
| 戰例庫回歸 | 準則更新後採納率不下降超過 5 個百分點 |
| 延遲 | 建議卡片首字出現 < 2 秒（串流） |
| 硬體 | 2018 年內顯筆電穩定 60 FPS，200 單位 |
| 每場 API 成本 | < US$0.15 |

## 本版不做（硬邊界）

- ❌ 不做多人連線
- ❌ 不做資源採集、基地建造（CoH 的經濟系統）；單位是開局配給
- ❌ 不做真實骨架動畫與全身物理；單位是膠囊體＋方塊頭，死亡才 ragdoll
- ❌ 不做語音輸入／輸出
- ❌ 不做自家代理伺服器與帳號系統；MVP 玩家自備 API 金鑰（BYOK）
- ❌ 不做 Steam 上架相關（成就、雲存檔）
- ❌ 不做參謀長「自動接管」模式（AI 直接指揮）——那會毀掉「玩家在訓練它」的核心感受

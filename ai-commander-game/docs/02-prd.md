# 02 一頁式 PRD：AI 參謀長 RTS（專案代號 CHIEF）

> 文件狀態：🟡 v0.3（2026-11-01，加入第二輪：D10、Token 計量、戰報卡）｜對應心智圖節點：`2. 核心玩法`、`3. 戰鬥沙盤`
> v0.1 → v0.2 改了什麼：AI 從「提建議」改成「全盤操作、玩家可隨時推翻」；加入常駐 AI 戰情板；多家模型與參謀長對決；單位改成班排連旅軍團；三語。

## 產品一句話

一款 TABS 風格的簡化即時會戰遊戲：AI 參謀長全盤指揮，玩家是總司令，隨時可以推翻它、親自接管任何一級部隊。每一次推翻都在訓練它，越打越像你的參謀長。

## 目標玩家

- 喜歡 Company of Heroes、Total War 的指揮感，但不想練 APM 的成年玩家
- 對 AI 好奇、願意自備 API 金鑰或跑本地模型的早期採用者
- 進階：想拿自己「養」出來的參謀長跟別人（或官方版）對決的玩家

## 核心體驗：三個層次

1. **看**：AI 參謀長在指揮，旁邊的「AI 戰情板」即時顯示它看到什麼、想什麼、下了什麼令。
2. **推翻**：玩家覺得不對，點一個排、一個連、甚至整個旅，直接接管下令；放手後 AI 接回。
3. **成長**：戰後檢討把「玩家在哪裡推翻了我、結果如何」寫進作戰準則；下一場它就不會再犯。

## 使用者流程（一場會戰）

1. 選地圖與規模（遭遇戰：班排；會戰：連旅；大會戰：旅軍團）→ 選參謀長包與模型
2. 開局：參謀長讀準則，一句話說明「我記得您偏好……」，然後直接開始指揮
3. 戰鬥中：戰情板側欄即時更新；參謀長每個節拍下令並附一句理由；玩家隨時可接管任何部隊
4. 關鍵事件：部隊潰散、據點易手 → 參謀長插話並調整
5. 戰後：戰報卡（30 秒看完）→ 討論（最多三回合，點選項或打字）→ 一鍵採納 → 準則「新增 N 條、刪除 M 條」→ 可撤銷
   - 全程 HUD 顯示本場花費；對決模式顯示雙方模型與各自花費
6. 下一場：第 3～5 場玩家應明顯感到「它懂我了」

## 成功定義

| 指標 | 目標 |
|---|---|
| 推翻率（玩家接管次數／AI 下令次數） | 第 1 場 > 40%，第 5 場 < 15%（同一玩家） |
| 戰例庫回歸 | 準則更新後模擬戰果不下降超過 5% |
| 延遲 | 參謀長命令首字出現 < 2 秒（串流）；戰情板更新 < 100 ms |
| 硬體 | 2018 年內顯筆電穩定 60 FPS（會戰規模） |
| 多模型 | 同一個參謀長包在至少 3 家供應商上能完整打完一場 |
| 每場 API 成本 | Haiku 等級 < US$0.15；本地模型 0 |
| 費用估算準確度 | 與供應商帳單相差 < 10%（有回傳 usage 的供應商） |
| 戰後流程時長 | 戰報卡＋討論＋採納，中位數 < 2 分鐘；跳過率 < 30% |

## 本版不做（硬邊界）

- ❌ 不做多人連線（參謀長對決是本機兩個 AI，不是兩個玩家）
- ❌ 不做資源採集與基地建造；單位是開局配給。**本遊戲玩的是會戰，不是大戰略**
- ❌ 不做真實骨架動畫與全身物理；單位是膠囊體＋方塊頭，死亡才 ragdoll
- ❌ 不做語音輸入／輸出
- ❌ 不做自家代理伺服器與帳號系統；玩家自備金鑰或本地模型（BYOK）
- ❌ 不做 Steam 相關（成就、雲存檔）
- ❌ 不做「純建議模式」（AI 只提議不動手）——那會變成另一款遊戲；可以留作旋鈕，但不是本版

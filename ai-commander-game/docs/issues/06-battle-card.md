# 06 戰報卡＋討論＋採納準則

**重用**：Rich 面板；閘道（03／04）。自製：三幕挑選、徽章規則、討論回合限制、準則 diff。

## 做什麼（老闆視角）
戰後 2 分鐘流程：一張戰報卡（戰果、推翻次數、花費、徽章、關鍵三幕）→ 最多三回合討論（每回合給 3 個快速回覆，也能打字，參謀長回覆限兩句）→ 準則 diff 一鍵採納或不採納 → 可撤銷。下一場開局參謀長會引用新準則（「上次您說……」）。

## 驗收清單
- [ ] 戰後自動顯示戰報卡；三幕優先挑推翻點，不足補轉折點（據點易手／潰散）；不呼叫 LLM（測試：關掉閘道也能出卡）
- [ ] 徽章至少 3 種（果斷總司令、放手型、省錢贏家），規則離線判定，手算例子當測試
- [ ] 討論：最多 3 回合，自動結束；每回合顯示 3 個快速回覆；AI 回覆超過 2 句時截斷並記錄
- [ ] 採納：顯示新增／刪除各 ≤ 3 條；採納後 `harness/<name>/doctrine.md` 更新且 ≤ 2,000 字；`--undo` 還原上一版
- [ ] 下一場開局第一句引用最近一次採納的條目
- [ ] 戰後流程可 `--skip` 跳過

## 30 秒驗收腳本
打完一場 → 看到戰報卡 → 選一個快速回覆 → 看到準則 diff → 按採納 → 再開一場，參謀長開局引用剛採納的內容。

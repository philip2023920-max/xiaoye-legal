- [ ] 會戰結束 → 全螢幕面板：勝負與星數、據點、推翻次數與率、費用、徽章、關鍵三幕表、提示、參謀長一句話（`/aar/line`）
- [ ] 討論：三個快速回覆按鈕＋輸入框，最多三回合，參謀長回覆兩句內；「直接採納」「跳過」
- [ ] 提案：顯示摘要、新增（綠）、刪除（紅）；「採納」→ 服務套用＋回歸（退步自動回滾的訊息顯示）；「撤銷」；aar.json 由服務寫
- [ ] 流程計時顯示（目標 < 2 分鐘）；「再打一場」回到開局
- [ ] 無頭測試：用 fake 服務走完卡 → 討論 → 採納的畫面狀態

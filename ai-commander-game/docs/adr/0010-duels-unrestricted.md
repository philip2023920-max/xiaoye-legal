# ADR-0010 參謀長對決不設公平限制
- 日期：2026-11-01
- 狀態：已採納（老闆第二輪拍板，否決 Claude 的「同模型同戰例」建議）
- 背景：Claude 原建議排名賽限制同模型同戰例，避免有錢用強模型的人永遠贏。
- 決定：不限制。任何參謀長包可搭配任何供應商與模型對決；願意花錢的玩家得到優勢是設計意圖。遊戲要把對決雙方的模型與花費醒目顯示（例如「DeepSeek V3 vs Claude Fable 5.1」），讓對決本身成為可看、可談論的內容。
- 放棄的方案與原因：同模型同戰例排名（限制了「看不同模型對打」這個核心賣點）。
- 後果／代價：排行榜要分欄顯示模型與每場花費，否則排名沒有意義；需要 Token 計量（F13）才能顯示花費；弱模型玩家需要有其他成就感來源（例如「用便宜模型打贏強模型」的徽章）。

# ADR-0013 戰鬥模型 v1：七種兵種、科技世代、天氣時段、資料表驅動
- 日期：2026-11-01
- 狀態：已採納（老闆第四輪「全照建議」）
- 背景：老闆要求兵種配比指揮、二戰到冷戰科技、天氣地形影響。M0 目前的 3 兵種＋簡化傷害公式是替身，只用來驗證迴圈。
- 決定：施工單 08 把戰鬥模型改成資料表驅動（`rules/<era>.json`：兵種 × 屬性、地形 × 天氣 × 時段 × 兵種修正、點數成本），老闆可改表不碰程式。v1 兵種七種（步兵、機槍、迫砲、反戰車、戰車、偵察、工兵）；科技世代三個，v1 先填二戰 1944；天氣四種 × 日夜兩種，一場中可變；場內砲兵納入，空中支援留 M3。開局加「部署階段」：點數預算採購＋三種編組範本。戰情板合約加天氣、時段、世代、裝備欄位。
- 放棄的方案與原因：維持 3 兵種（參謀長學到的準則沒有戰術意義）；一次做三個世代（表格格式沒定好就填資料會重做）；v1 就做空中支援（整套新機制，會卡住 M0）；把修正寫死在程式裡（違反老闆要能調整的需求與 ADR-0011）。
- 後果／代價：壓縮快照會變大，要維持 < 2K token；系統提示要教參謀長這些修正；敵方劇本與驗收腳本要重做；玩具沙盤上學到的準則在 08 完成後歸零；M1 引擎的單位、地形、天氣都吃同一份表，08 必須在 M1 之前完成。

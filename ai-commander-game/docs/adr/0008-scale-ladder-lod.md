# ADR-0008 規模階梯與細節層級
- 日期：2026-11-01
- 狀態：已採納（老闆第三輪「全照建議」）
- 背景：老闆要可控層級到軍團，同時要低硬體需求與 TABS 式物理。數千人每人一個布娃娃在內顯筆電上跑不動。
- 決定：三級規模階梯。遭遇戰（班排，20～100 人）每人一個方塊人、死亡 ragdoll；會戰（連旅，500～2,000 人）一個班＝一組三個方塊人代表十人，只有鏡頭附近有 ragdoll；大會戰（旅軍團，5,000 人以上）連以上用棋子，拉近鏡頭才展開，棋子無物理。
- 放棄的方案與原因：全規模每人一個布娃娃（物理上不可行）；只做遭遇戰（放棄老闆要的軍團層級）。
- 後果／代價：單位渲染要做 LOD 切換；戰情板的部隊樹在不同規模下的最小單位不同（班／連），資料格式要帶 `scale` 欄位；效能驗收以會戰規模為準。

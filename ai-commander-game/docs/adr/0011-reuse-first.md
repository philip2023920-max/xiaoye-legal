# ADR-0011 重用優先：先找現成素材與模板，再改，最後才自製
- 日期：2026-11-01
- 狀態：已採納（老闆指示）
- 背景：老闆不希望所有元素從頭製作，要盡量蒐集可用素材與模板，改動或直接利用。
- 決定：每張施工單動工前必須先做「重用檢查」：列出候選的開源專案／素材包／套件與授權，能直接用就用，能改就改，找不到才自製並寫明理由。目錄維護在 `docs/07-reuse-catalog.md`，進專案的東西記錄在 `THIRD_PARTY.md`。授權優先序 CC0 ＞ MIT／Apache ＞ CC-BY ＞ 其他（先問老闆）。
- 放棄的方案與原因：全部自製（慢、品質低、重造輪子）；不看授權就用（商業化時出事）。
- 後果／代價：要花時間驗證授權與版本相容；套件更新可能破壞相容，要鎖版本；美術風格要靠換色與統一材質來一致化，不能混搭太多來源。
